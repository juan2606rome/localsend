# Send Widget v1.2.0

Selector de color renovado, recorte de fotos al elegirlas, cambio automático configurable y una ventana de inicio con los botones de LocalSend.

## Novedades

**Al tocar el widget**
- Aparece primero una ventana para elegir entre **Recibir** y **Enviar**, con los mismos botones e iconos de LocalSend. Al elegir Enviar se abre el menú de agregar archivos.

**Selector de color**
- Nuevo cuadro de intensidad y brillo con barra de tono, en lugar de las barras separadas.
- Caja para escribir el código del color (#RRGGBB) con aplicación inmediata.
- Botones para copiar el color actual y pegar uno desde el portapapeles. Tocar la muestra también lo copia.

**Fotos**
- Las fotos se eligen primero desde la galería, con sus álbumes. El explorador de archivos queda como segunda opción.
- Al elegir varias fotos a la vez, se abre el recorte de cada una en secuencia. Se puede omitir una, o dejar el resto para después y recortarlas tocando su miniatura.

**Cambio automático**
- Nueva opción para elegir cada cuánto cambian los colores y las fotos: cada día, 6 horas, 1 hora, 30 minutos o 15 minutos.
- Usa alarmas que no despiertan el dispositivo, para mantener bajo el consumo de batería.

**Ajustes**
- El botón inferior ahora es «Guardar widget» solo en el menú principal; dentro de cada sección es «Listo».
- Al salir del menú principal con «Atrás» se pide confirmación antes de descartar los cambios.
- El interruptor del título «Enviar archivos» también está en la sección Botón de ajustes.

## Instalación

Descarga el archivo APK, ábrelo en tu Android y permite la instalación desde este origen si el sistema lo solicita. Para actualizar desde una versión anterior, instala el APK encima: se conservan tus widgets y su configuración.

Compilado para dispositivos de 64 bits (arm64), que incluye casi todos los celulares actuales.
